# PROJECT_X - 2D Fighting Game Prototype

PROJECT_X is a prototype for a 2D fighting game developed by Group 21 for CEN4090L. This project leverages the Unity game engine for rapid development and Blender for asset creation. The aim is to create a foundational framework for a competitive and visually engaging fighting game.

## Features

- Core mechanics of a 2D fighting game, including movement, attacks, and a match timer
- Multiple playable characters with unique skins
- Handcrafted assets using Blender and animated using Unity's animation system
- Modular codebase for easy expansion with new characters, levels, and mechanics
- Support for local multiplayer matches

## Getting Started

1. Clone the repository.
2. Open the project in Unity (recommended version: 2020.1 or newer).
3. Install required Unity packages if prompted.
4. Run the main scene to start the prototype.
